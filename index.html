Provedores de IA por API

🔑 Criar / gerenciar chave📚 Documentação da API

O ID precisa corresponder exatamente ao nome disponibilizado na sua conta. As sugestões são exemplos e podem mudar conforme o provedor.

⚙️ Parâmetros avançados de geração

Alguns modelos não aceitam temperatura ou possuem limites próprios. Se houver erro de parâmetro, reduza as opções ou use a configuração padrão do provedor.

A chave fica somente nesta sessão do navegador. Como o site é estático, chamadas diretas expõem a chave ao navegador; para uso profissional contínuo, prefira um backend/proxy privado. Nunca compartilhe sua chave.

IA local — Ollama

⬇️ Baixar Ollama🧠 Biblioteca de modelos📚 API / documentação
O modelo precisa estar baixado no computador (por exemplo, pelo comando ollama pull qwen2.5). Como o gerador está hospedado no GitHub Pages, o Ollama precisa permitir a origem https://mpjbiologo.github.io em OLLAMA_ORIGINS. Se o teste retornar “Failed to fetch”, consulte as instruções detalhadas exibidas no diagnóstico. Reinicie o Ollama depois de alterar a variável. Não exponha a porta 11434 à internet.
